Compilador Func xp

Extensão da linguagem das atividades da disciplina

João Marcos Cunha Santos

Módulos do compilador RUST

  1. lexical.rs — tokens (números, keywords, operadores, strings…)
  2. syntax.rs — parser → AST (expressões, comandos, funções)
  3. resolve.rs — importa libs e qualifica alias::nome
  4. semantic.rs — tipos, escopos, existência de main
  5. generation.rs — emite assembly x86-64; _start chama main

Fluxo em main.rs: ler → tokenizar → parsear → resolver → validar → gerar.

O que foi adicionado

23 features além da gramática base das atividades.

  • Tipos e declarações tipadas
  • func / main tipados
  • return em qualquer lugar
  • Retornos list / bool / text
  • print, comentários
  • Lógicos e comparações extras
  • Módulo, unário, compostos
  • Listas + builtins
  • Métodos e encadeamento
  • bool e text
  • Imports e libs padrão
  • Argv em main

Feature

1. Sistema de tipos

Exemplo

num x = 42;
bool ok = true;
list a = [1, 2, 3];
text t = "hi";

Implementação

Enum Type { Num, List, Bool, Text } em syntax.rs. O léxico reconhece as keywords; a semântica (semantic.rs) valida compatibilidade em atribuições, parâmetros e retornos.

Feature

2. Declarações tipadas

Exemplo

// base: var x = 10;
// Func:
num x = 10;
list xs = [];

Implementação

Substitui var por <tipo> <ident> = <exp>;. Parser em extract_variable_declaration; o tipo fica na AST e é checado na análise semântica.

Feature

3. Funções tipadas (func)

Exemplo

func add(num a, num b) num {
  return a + b;
}

Implementação

Keyword func (em vez de fun). Cada parâmetro carrega tipo; o tipo de retorno vem após os parênteses. Validado em semantic.rs contra o return efetivo.

Feature

4. main como função tipada

Exemplo

func main() num {
  return 42;
}

Implementação

Não há mais forma especial main { }. main é uma Function normal; a semântica exige que exista e que o último comando retorne num ou bool. O runtime chama main a partir de _start.

Feature

5. return como comando (qualquer lugar)

Exemplo

func abs(num x) num {
  if x < 0 {
    return 0 - x;
  } else {
    return x;
  }
}

Implementação

Na base o return ficava só no fim do corpo. Em Func, Command::Return pode aparecer em qualquer bloco. A geração emite pop %rbp; ret com o valor em %rax.

Feature

6. Retorno de list / bool / text

Exemplo

func make() list {
  list t = [1, 2];
  t.push(3);
  return t;
}

func main() num {
  return make().len;
}

Implementação

O tipo de retorno da função é checado semanticamente. Listas/textos retornam o handle (ponteiro) em %rax — a mesma convenção de valores numéricos/bool.

Feature

7. Declarações misturadas com comandos

Exemplo

func main() num {
  num acc = 0;
  while acc < 3 {
    num step = 1;
    acc = acc + step;
  }
  return acc;
}

Implementação

vardecl passou a ser um Command (não só prefixo do corpo). Locais recebem slot na pilha em generation.rs via offset relativo a %rbp.

Feature

8. Comando print

Exemplo

func main() num {
  print 42;
  print xs[i];
  return 0;
}

Implementação

Keyword print → Command::Print. O module generation avalia a expressão e chama imprime_num do runtime (templates/runtime.s).

Feature

9. Chamada como statement

Exemplo

list a = [];
push(a, 3);
io::printBool(true);

Implementação

Parser aceita expressão de chamada/método como comando (Command::FunctionCall). O valor de retorno em %rax é descartado — útil para efeitos como push e print*.

Feature

10. Comentários //

Exemplo

// soma parcial
num x = 1 + 2;

Implementação

Tratados no léxico (lexical.rs): ao ver //, o restante da linha é ignorado e não gera tokens.

Feature

11. Operadores lógicos and / or / not

Exemplo

func main() num {
  num a = 5;
  num b = 10;
  return (a < b and b > 0) or (not (a == b) and a + b > 10);
}

Implementação

Precedência: or < and < comparação. not é unário. module generation normaliza operandos com test/setnz e aplica and/or em registradores.

Feature

12. Comparações <= e >=

Exemplo

return (a <= b) and (c >= a);

Implementação

Tokens LessEqual / GreaterEqual no léxico. Na geração: cmp + setle / setge → resultado 0/1 em %rax.

Feature

13. Operador módulo %

Exemplo

func main() num {
  return 17 % 5;  // 2
}

Implementação

Mesmo caminho de divisão (cqo + idiv); para % o resultado vem de %rdx (resto) em vez de %rax.

Feature

14. Menos unário

Exemplo

num x = -3;
return 0 - x;

Implementação

Parser em get_expression_unary: - antes de um primário vira UnaryOperation(Sub). module generation: neg %rax.

Feature

15. Atribuições compostas e ++

Exemplo

n++;
n += 2;
n *= 2;
acc -= 3;
acc /= 7;

Implementação

Tokens PlusEqual, MinusEqual, MulEqual, DivEqual, Increment. O parser desaçucara para leitura + operação + atribuição antes da geração.

Feature

16. Listas dinâmicas

Exemplo

list a = [10, 20, 30];
list empty = [];
a[1] = 99;
return a[0];

Implementação

Literais [...] → ArrayLiteral → array_new no runtime (heap via brk). Handle aponta para [len][cap][data...]. Indexação: offset 16 + i*8.

Feature

17. Builtins .len, .push(), .pop()

Exemplo

list a = [];
a.push(1);
a.push(2);
num n = a.len;
num last = a.pop();

Implementação

Desaçucarados para chamadas especiais no module generation: array_push, leitura do campo len, array_pop. .len aceita parênteses opcionais.

Feature

18. Métodos e encadeamento

Exemplo

num x = -3;
return x.abs();

list a = [1, 2, 3];
num s = a.mult(2).push(2).sum();

Implementação

apply_method_calls transforma recv.f(args) em f(recv, args). Encadeável: o resultado da chamada vira receptor da próxima. Também funciona com namespace: x.ss::count().

Feature

19. Tipo bool e literais

Exemplo

bool y = true;
bool z = false;
if y {
  return 1;
} else {
  return 0;
}

Implementação

true/false viram literais 1/0 no parser. Em if/while, 0 é falso e qualquer outro valor é verdadeiro (cmp $0, %rax + salto).

Feature

20. Tipo text e strings

Exemplo

text t = "hello";
return t[0];  // 104 = 'h'

Implementação

Literais string no léxico (StringLiteral). module generation cria um array com códigos ASCII — mesmo layout de list. Indexação e .len compartilham a implementação de arrays.

Feature

21. Imports e namespace alias::

Exemplo

import ss from "./sum_lists"

func main() num {
  list x = [1, 2, 3];
  return x.ss::count();
}

Implementação

Fase resolve.rs: lê o arquivo, reescreve símbolos com prefixo alias::, mescla decls no programa. Libs não podem ter main nem imports aninhados. Identificadores aceitam :: no léxico.

Feature

22. Bibliotecas padrão

Exemplo

import n from "../../lib/numbers.lib"
import ls from "../../lib/lists.lib"
import io from "../../lib/print.lib"

func main() num {
  return n::factorial(5) + [1,2].ls::sum();
}

Implementação

Arquivos em lib/ escritos na própria linguagem: numbers.lib, lists.lib, print.lib. São compilados junto via resolve — não há runtime especial além dos builtins de array/print.

Feature

23. Argumentos de linha de comando em main

Exemplo

// ./prog 3 string 4  →  122
func main(num a, text s, num b) num {
  return a + s[0] + b;
}

Implementação

_start salva o stack do SO (__argv_base). Para cada parâmetro de main: parse_num ou parse_text; se faltar argv, usa default (0 ou lista vazia).

Como executar

cargo run <arquivo>
as -o output/target_code.o output/target_code.s -Itemplates
ld -o output/target_code output/target_code.o
output/target_code
